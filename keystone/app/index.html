An agentic operating system for Habitat for Humanity Orange County's Keys to 100. It finds land with a CNN, keeps families housed with a Monte Carlo mortgage designer, sizes the capital gap on real HMDA data, and improves itself through gated champion/challenger loops. Family sustainability designer

Two-layer simulate-and-optimize (Ardon et al. 2024). The inner layer is a 10-year monthly Monte Carlo with job loss, insurance shocks, repairs and stewardship. The outer layer searches 108 mortgage designs for the cheapest one that keeps P(sustained ownership) at or above the target.

Agent hierarchy

Director (Claude Opus 5.5) → division leads (Opus 5.5) → workers (Sonnet 5.5). Every tool call goes over MCP to the Euodos server; analysis code runs in the OS sandbox. Without API credentials the same hierarchy runs a deterministic scripted policy.

Self-improvement

Agents may recommend. Deterministic gates decide. A challenger, whether a CNN, a credit model or an agent playbook, is promoted only if it beats the champion on the same frozen evaluation and passes its guardrails (fairness gap for credit models).
